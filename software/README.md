# Software

The parent's end: a phone web app (PWA). Record, send, listen to replies.

Nothing here yet.

## Requirements

- Works on a phone browser with no install and no app store.
- Hold-to-record with the same 60 s cap as the box.
- Shows whether a message reached the box, and when it was played.
- Surfaces every failure that the box deliberately hides from the child.
- Quiet-hours setting, enforced on the device.

It is a client of the same protocol a second box would speak — nothing
app-specific belongs in the firmware.
